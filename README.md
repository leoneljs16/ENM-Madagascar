# Examen National Maths Madagascar (ENM Madagascar)

Application Android gratuite et hors ligne pour préparer les examens nationaux
de mathématiques (BEPC et Baccalauréat) à Madagascar.

## Compiler l'APK (sans rien installer)

1. Onglet **Actions** → workflow **Build APK** → **Run workflow**.
2. Attendre la fin (environ 5 à 10 minutes la première fois).
3. Ouvrir l'exécution terminée → section **Artifacts** → télécharger
   `ENM-Madagascar-debug-apk` (fichier ZIP contenant `app-debug.apk`).

## Installer sur un téléphone

1. Extraire le ZIP et ouvrir `app-debug.apk`.
2. Autoriser l'installation depuis cette source si Android le demande.
